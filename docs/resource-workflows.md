# 资源操作与交互约定

列表面向日常任务，不能仅把 API 参数表移入弹窗。`resource-model.mjs` 明确维护每类资源的优先字段、默认值和说明；`ResourceDialog` 负责上下文、加载与提交，`SchemaForm` 复用字段控件和校验约束。「全部操作」保留接口级工作台，不作为列表详情与基本维护流程。

## 各栏目场景

| 栏目       | 创建 / 基础维护的优先场景                                      | 其他交互                                                                         |
| ---------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 虚拟服务器 | 命名、可见性、团队，按名称搜索并批选工具、资源、提示词、智能体 | 直接读取详情；编辑从完整 GET 回填；复制 MCP 连接配置；启停、删除有目标上下文     |
| MCP 网关   | 上游 URL、Streamable HTTP / SSE、认证方式、可见性              | 按认证方式展示相关凭据；重发现等操作自动绑定当前网关                             |
| 工具       | 创建本地 REST 工具，配置 HTTP 端点、调用方法和输入输出结构     | MCP 服务接入直接打开网关创建流程；MCP / A2A 工具通过各自来源管理                 |
| 资源       | URI、名称、MIME 类型、内容                                     | 内容使用多行编辑器，URI 和内容必填预检查                                         |
| 提示词     | 名称、正文、可见性，逐项添加参数                               | 参数具有名称、说明和必填开关，不要求先手写数组                                   |
| A2A 智能体 | 端点、协议和认证                                               | URL 预检查；认证字段随认证类型显示                                               |
| Roots      | 根 URI、可选名称                                               | 使用后端实际提供的创建和删除能力                                                 |
| API Key    | 名称、默认 30 天、团队、可选服务器和明确的授权方式             | 继承账户 / 自定义权限二选一；模板、搜索、批选；自定义空选禁止提交；明文单独交付  |
| 团队       | 名称、可见性、短名称、人数上限、逐项添加初始成员               | 成员、邀请、加入请求绑定团队；需要其他用户 / 邀请 ID 的操作继续选择目标          |
| 用户       | 邮箱、显示名、初始密码、首次修改密码、账户类型                 | 默认要求首次修改密码；账户维护不再要求重新填写已知路径 ID                        |
| 角色       | 名称、范围、权限、继承                                         | 角色分配按选定范围过滤角色；团队分配必须选团队；撤销保留原作用域                 |
| 模型供应商 | 供应商类型、基础地址、凭据、默认模型                           | 供应商类型下拉；不回填返回的加密 / 占位凭据；模型等相关操作绑定供应商            |
| 插件       | 查看已安装插件并更改运行模式                                   | 模式使用后端枚举；导入用于批量更改已有插件模式，不虚构插件安装 API               |
| 服务目录   | 浏览已有目录，按项注册                                         | 无单项 GET 时直接呈现列表记录；注册绑定目录 ID，按要求填写凭据；导入用于批量注册 |

界面采用请求方法对应的 Schema。可选专业配置收在「更多配置」；新增后端字段仍可通过该区及接口工作台访问，不能无提示变成基本创建步骤。权限和实时接口可用性同时控制入口；后端仍是授权的最终依据。

行内「更多操作」按请求方法与完整路径定义中英文名称，区分成员查看 / 添加 / 修改角色 / 移除、邀请查看 / 发送、加入申请查看 / 批准 / 拒绝，以及退出团队与删除团队。菜单、弹窗标题与操作确认使用同一名称；未知操作明确显示请求方法和路径，不猜测为删除当前资源。共用表单、关联选择器与菜单无障碍名称随当前语言更新。

虚拟服务器创建和编辑的关联字段兼容 snake_case / camelCase，统一使用搜索复选框。名称、说明、ID 与工具来源可检索，支持仅已选 / 仅未选、匹配项全选 / 取消及清空；筛选不会清除其他已选项。同名项显示 ID 和来源，目录中不可见但完整详情已返回的关联 ID 继续保留并可移除。工具回填读取 `associatedToolIds`，不使用展示名称 `associatedTools` 作为 ID；资源、提示词与 A2A 的读取字段本身是 ID。写入采用请求 Schema 的字段别名与 ID 数组，清空发送 `[]`，编辑未改变的关联字段省略。v1.0.11 完整详情只返回启用关联，未返回的停用关联无法由前端还原；省略未改字段可避免编辑其他属性时重置它们。关联目录按接口声明分页，读取失败或分页不完整时保留已有选择并提示重试，禁止把部分目录显示成完整匹配项。

API Key 创建栏持续显示授权摘要。继承模式在运行时使用账户 RBAC 权限，仍受服务器、IP、时间和用量限制；自定义权限与账户权限取交集。清空自定义权限不会自动切回继承，必须明确选择继承或重新选择权限。创建结果展示后端返回的 `token.resource_scopes` 与 `warnings`。

资源弹窗只有内容区滚动，标题与操作栏保留在视口内；手机端全屏显示。工具详情先显示名称、用途、状态、来源与归属，配置分成调用配置、输入输出、访问控制、审计信息；原始数据默认折叠并继续脱敏。编辑、启停入口按已有权限和接口可用性显示。

连接指南与虚拟服务器行内连接入口复用配置生成器。选择服务器、客户端格式并粘贴 Key 后才能复制完整配置；预览隐藏 Key，Key 不写入浏览器持久存储。LLM 前缀优先从实时规范获取，无法确定时要求管理员提供 `LLM_API_PREFIX`，模型可从当前后端列表选择或手工填写。MCP 检查只进行初始化握手，LLM 检查只读取模型列表；检查成功不代表外部客户端、上游工具调用或实际模型生成通过。

## 列表查找与移动端

名称、说明、标签和 ID 搜索覆盖所选团队范围内的全部可访问分页，并可叠加状态和可见性筛选。标签兼容字符串数组与对象数组，搜索对象的 `label` 和 `id`，忽略大小写及搜索首尾空格；表格和手机卡片优先显示标签名称，默认展示三个，其余可展开。不带标签的资源不显示空占位。列表内团队选择与顶部团队上下文同步。接口声明支持 `team_id` / `visibility` 时先在后端缩小范围，其他条件在完整分页结果上匹配；不向不支持的接口臆造通用 `search` 或 `tags` 参数。无筛选时仍使用后端分页，有筛选时缓存全量快照并以每页 25 项展示结果。

跨页扫描支持 cursor、offset、skip 和 page，最多 10000 项。遇到分页失败、重复游标、无新结果或上限时明确报错，不展示成完整结果或空列表。修改筛选会回到第一页并清除旧批选，跨页批选与导出使用同一套筛选规则。当前后端角色列表实际只返回启用角色，不能用其 `active_only=false` 声称可查询停用角色。手机默认单列卡片，保留状态、详情与有权限时的编辑入口；用户可主动切回表格。

## 运维数据呈现

Trace ID 读取 `trace_id`，可用键盘进入详情和复制；Span 操作名读取 `name`。耗时统一按毫秒显示，最多两位小数，零值与缺失值区分。时间转为浏览器时区并显示偏移，悬停保留原始值；v1.0.11 的无时区时间按 UTC 解释。

指标接口的并列数组按 `buckets` 对齐：timeseries 的 `values` 是请求数，percentiles 的 `p50/p95/p99` 才是延迟。分位卡片展示最近有样本的单个时间桶，不将桶间分位数平均为整个窗口的分位数；空桶显示缺失，不冒充零延迟。时间桶表展示最近 24 桶，完整指标和查询性能响应收进高级详情。遥测关闭、权限不足与读取失败不会显示为零值成功。

## 导入导出格式与边界

资源列表的导入 / 导出、导出选中项、批量操作和虚拟服务器行内连接配置均直接打开工作流弹窗。日志 / 可观测性的查询快照入口位于顶部操作区；系统设置的原生配置迁移也通过弹窗完成。预检查、确认、逐项结果与失败重试留在同一弹窗，执行写入或导出时禁止关闭和 Escape，防止丢失执行结果。标题和关闭按钮固定，导入 / 批量执行按钮固定在底部，内容独立滚动；手机全屏显示。关闭后保留列表上下文，并在入口仍存在时恢复焦点。未提交的文件预览随关闭清除，重新打开需要重新选择文件。

资源列表提供与该资源场景相符的导入、导出、模板入口；工具页专门区分 REST 定义与工具清单。导出可针对选中项 / 当前页，或跨分页的全部匹配项。跨页过滤沿用列表的文本、状态、团队和可见性筛选，工具页还包括来源网关 ID，获取上限为 10,000 项。为了避免缺少内容或关联，存在单项 GET 时会逐项读取完整记录；失败时停止导出并显示错误，不伪装为完整备份。

### 工具接入与 REST 定义

REST 工具的认证放在主要配置中，支持 Basic、Bearer 和自定义请求头；按方式显示所需输入，切换方式会清除旧输入，凭据不完整时阻止提交。编辑时显示当前认证方式，GET 返回的掩码、密文和明文用户名均不回填到凭据输入。保持认证选项空白会保留已有凭据；明确选择 `none` 才清除认证。旧版前端曾把凭据写入读取用的嵌套字段，已受影响的工具需要重新输入凭据并保存。

v1.0.11 的工具认证写入契约与 OpenAPI 展示的 `AuthenticationValues` 读取结构有区别：创建时在 `tool` 内发送 `auth_type` 与对应的 `auth_username` / `auth_password`、`auth_token` 或 `auth_headers: [{key, value}]`；更新时发送在请求体根层。后端 `schemas.py` 的 `ToolCreate.assemble_auth` / `ToolUpdate.assemble_auth` 负责构造认证头和加密，前端不把嵌套 `username` / `password` / `token` 当作已编码认证写入。移除认证显式发送 `auth: {authType: "none", authValue: ""}`，因为只发送顶层 `auth_type: "none"` 不会清除已有配置。资源表单、接口工作台和 REST 导入共用写入映射。

工具创建时可选所属团队；请求体的 `team_id` 与表单当前选择一致，不由顶部团队筛选覆盖。v1.0.11 `ToolUpdate` 不接受团队变更：编辑表单显示完整 GET 返回的既有团队并保持只读，以该归属校验 `team` 可见性，PUT 不夹带团队字段。未分配团队的工具不能在编辑时改为团队可见，界面禁用该选项并说明需在创建时指定团队。该流程不提供后端未支持的团队迁移。

工具列表、手机卡片和工具详情提供「测试调用」，需要 `tools.read`、`tools.execute`，且完整详情与 `/rpc` 在运行时可用。打开时重新 GET 完整工具记录，使用后端发布的 `name` 和 `inputSchema`（兼容 `input_schema`），不把 `originalName` 当作调用名称，也不使用列表中的旧 Schema。读取失败、缺少 Schema 或工具停用时禁止调用。

测试参数按独立 JSON Schema 渲染必填项、默认值、字符串、数值、整数、布尔、保留原类型的枚举、嵌套对象和数组；支持本地 `$defs` / `definitions` 引用。工具参数不套用控制台资源字段的权限、认证或可见性推断。联合类型、复杂组合、开放对象和深层递归字段保留 JSON 编辑，整个参数对象可随时切换 JSON 模式以填写额外字段。无效 JSON 不得提交旧的有效值。使用不依赖动态代码执行的 JSON Schema 校验器，兼容现有 CSP；不支持的 Schema 会明确提示交由后端完整校验，后端始终负责最终规则、权限与资源归属。

点击「调用工具」会真实执行 `POST /rpc` 的 `tools/call`，可能修改上游数据。弹窗展示响应正文与请求耗时；HTTP 错误、JSON-RPC `error` 和 MCP `result.isError` 均显示失败，并保留参数。执行期间禁止重复调用与关闭；「停止等待」中断浏览器请求并立即释放界面，不保证撤销已在上游执行的操作。旧请求的迟到结果不会覆盖后续调用，界面不自动重试。v1.0.11 的管理员私有工具调用存在后端过滤限制，列表可见不保证 RPC 可调用，见验证记录。

工具页的「接入 MCP 服务」进入 `#gateways?connect=1` 并立即打开现有网关创建弹窗，消费创建意图后清除 URL 参数；入口按网关创建权限和接口可用性显示，不额外要求网关读取权限。连接错误保留配置以便修正，成功返回网关后按后端 `status`、`reachable` 展示已连接、等待发现或尚未就绪，不能把异步登记当成发现成功。发现数量通过完整分页工具清单按网关 ID 统计；接口声明支持时发送 `gateway_id` 缩小范围，并在客户端按精确 ID 再过滤，只代表当前账户可读取的数据。读取失败不显示零值。有网关读取能力时可以手动刷新，先 GET 网关详情再读取清单，不额外执行写入或自动重注册。「查看发现的工具」返回 `#tools?gateway=<ID>`，按精确来源 ID 跨页筛选；该条件也用于批选和导出，且可以单独清除。没有工具读取能力时不读取清单，也不提供返回工具的按钮。连接与发现均不证明实际工具调用成功。

「创建 REST 工具」与「REST 工具导入 / 导出」只创建本地 REST HTTP 工具；创建表单不提供 MCP / A2A 类型或上游网关绑定。导入仍使用下文 `contextforge-panel` version 1、`resource: tools` 的包裹格式，兼容已有本地 REST 定义与未显式指定类型的旧记录（按 REST / POST 补齐）。模板使用 `lookup_order` 的 POST JSON 示例，解释 URL、HTTP 方法、`inputSchema` 与 `records` 的关系；它不是 OpenAPI / Swagger 文档，也不是 MCP 客户端配置。预检查拦截 MCP / A2A 类型、来源网关 / gRPC 关联、非 HTTP 请求方法与缺失 URL，不能通过 `allow_auto` 绕过类型限制。混合文件逐行报告问题，修正前不执行任何创建请求。

REST 定义导出仅包含本地 REST 工具，混合范围跳过服务管理工具并明确报告数量；没有合适记录时提示改用快照，不输出空的可创建包。独立「导出工具清单快照」覆盖所有类型，标记 `kind: snapshot`，经过脱敏且禁止作为创建配置导入。两种导出均支持已选 / 当前页和跨页全部匹配项。REST 定义排除凭据，需要重新配置认证；MCP 服务备份与迁移使用系统设置的原生流程迁移网关配置，再由网关发现工具，不逐项重建发现记录。

资源模板格式：

```json
{
  "format": "contextforge-panel",
  "version": 1,
  "resource": "servers",
  "kind": "create",
  "records": [{ "name": "example", "visibility": "private" }]
}
```

`records` 是未包裹的创建对象；发送时由界面补齐对应 API 的外层结构。插件记录包含 `name` 和 `mode`，目录注册记录包含 `catalog_id` 与注册配置。导入前检查版本、栏目、文件大小、条数、必填、类型、枚举、数值范围、已知 URL / 邮箱 / IP 格式、文件内重复与当前已加载记录的同名冲突。检查覆盖全部记录，表格先展示前 50 行；其余错误可展开。

需要确认后才会写入。逐项执行，最大并发 3，不提供事务回滚；结果保留失败原因，可仅重新预览失败项，再确认重试。已成功项不会自动重复提交。不能仅依据预检查声称后端唯一性、上游连接、动态密码策略或资源归属已经验证。

可创建配置导出排除已知凭据、只读字段和原身份信息；认证需要有意重新配置。关联 ID 保留且**只保证适用于原环境**，不会按同名资源自动重绑。跨环境迁移复杂依赖建议使用系统设置的原生迁移入口。用户导出不含密码；导入用户需补充初始密码。Key 导入签发新 Key，无法还原原有 Key；批量签发的明文只保存在当前组件内存，必须及时逐个复制，关闭弹窗或离开栏目后无法重新取得。

只读接口或无写入权限时，提供快照导出、模板和本地导入预览，不伪造写入能力。日志 / 审计 / 指标没有历史写入 API：使用 `contextforge-panel-history` 格式，只导出当前查询已加载的数据，导入清楚标为「未写入后端」。

## 日志、可观测性和系统配置

日志有文本、级别、时间、用户、组件、类别和关联 ID 检索，支持日志分页；审计、安全事件、用户活动和性能记录分别呈现。关联 ID 读取关联详情。筛选起止时间先在前端检查，避免反向时间段请求。级别使用复选框，无需 Ctrl 多选。各视图依其真实权限获取数据。

日志、审计、安全事件和 trace 列表默认每页 20 条，可切换 20 / 50 / 100 条。筛选提交和每页条数变化回到第一页；各列表独立保留页码。日志搜索使用响应的 `total`；审计、安全事件和 trace 的 v1.0.11 响应没有总数，使用 `limit=pageSize+1`、`offset=page*pageSize` 查询，仅展示前 `pageSize` 条，以多取的一条判断下一页，不推算总页数。活动流仅支持最近记录及 `since` 增量语义，展示最近最多 100 条并限制滚动区域，不提供更旧历史翻页。

点击 trace ID 或日志关联 ID 即打开详情弹窗；也可检索关联 ID 后点击“查看关联详情”，包括没有匹配日志的情况。关闭或 Escape 返回原入口，保留列表页码和滚动位置。手机使用全屏弹窗，标题与关闭按钮固定、内容区滚动。Trace 使用详情接口中的完整 `spans`，按开始时间降序在客户端分页，原始详情保留嵌套 events；不再额外请求最多 100 条的 spans 列表。详情和关联日志接口本身没有分页参数，因此这里只限制显示量，不能减少完整详情响应的网络大小。

可观测性单独展示指标时间窗口、时间序列、分位数、追踪过滤、追踪与 span 详情。清理历史追踪需确认；接口关闭时不发送相应请求。

系统配置将允许透传的请求头作为明确可写设置，编辑 / 导入先产生增删差异，确认后才 PUT；支持 HTTP 头名称校验、模板与缓存维护。其余运行参数按后端配置组显示，默认收起大部分组，并支持搜索。已知凭据字段及含密码的 URL 被隐藏；Token 用量等数值不会因为名称含 tokens 被误遮挡。

原生备份调用 `/v1/export`，支持选实体、停用项、依赖；原生迁移调用 `/v1/import`，先 `dry_run: true`，选择 skip / update / rename / fail 策略，预检查完成且无失败后确认实际导入。v1.0.11 原生迁移只支持 tools、gateways、servers、prompts、resources、roots。原生备份可能包含加密认证配置；导入端必须能够解密已有认证信息。高级参数 `rekey_secret` 是重加密后的新密钥，后端先以当前密钥解密，再使用该新密钥加密，普通恢复留空。模板不可与资源列表的创建模板混用。导入身份、团队与可见性以后台的导入约束为准。

## 验证要求

接口工作台对后端直接读取 `Request.body()` / `Request.form()` 的已核对路由补充请求体契约，包括 `/rpc`、协议操作、消息转发、App Bridge、日志级别及部分 admin 接口。补充仅针对源码已证实的请求体，不由 POST 推断参数。已知字段渲染控件，字段列表不完整的接口提供 JSON 编辑并提示实际提交的 JSON / URL-encoded 格式；原有无请求体操作仍保留无参数语义。补充与实时规范合并后仍保留，接口可用性仍由实时规范决定。工作台也展示 HTTP 200 中的 JSON-RPC 错误。

界面改动执行 `npm run check`、`npm run format:check` 和真实后端浏览器测试。反代和权限相关改动追加 `npm run test:integration`。控件行为、模板往返、动态接口不可用、部分成功和凭据交付需单独关注。已运行场景与未覆盖边界记在 [verification.md](verification.md)，接口覆盖枚举不是业务端到端通过证明。
